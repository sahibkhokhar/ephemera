# Ephemera — agent setup

The agent skill is at **`skills/ephemera/`** (Agent Skills format).

**Skill URL:**  
https://raw.githubusercontent.com/sahibkhokhar/ephemera/main/skills/ephemera/SKILL.md

Paste this into your agent (replace URL and key):

```
Load the Ephemera skill directory or fetch:
https://raw.githubusercontent.com/sahibkhokhar/ephemera/main/skills/ephemera/SKILL.md

My instance:
  EPHEMERA_URL=http://192.168.1.50:8000
  EPHEMERA_API_KEY=                    # leave blank if writes are open
```

Install Ephemera: https://github.com/sahibkhokhar/ephemera#quick-start
