API shape

POST /api/artifacts
{
  "title": "Log excerpt",
  "kind": "log",
  "ttl_minutes": 30,
  "content": "..."
}

Response includes the artifact id, expiry timestamp, and a temporary URL such as {{ base_url }}/a/....

What it is good at

  • Large logs with context
  • JSON and nested structures
  • Markdown writeups and summaries
  • Images and image notes
  • Short-lived reports for quick review
