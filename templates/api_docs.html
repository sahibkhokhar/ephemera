Create an artifact

POST /api/artifacts

bash 
curl -s {{ base_url }}/api/artifacts \
  -H 'content-type: application/json' \{% if auth_required %}
  -H 'x-api-key: $API_KEY' \{% endif %}
  -d '{
    "title": "Nightly job log",
    "kind": "log",
    "ttl_minutes": 120,
    "content": "..."
  }'

201 Created
